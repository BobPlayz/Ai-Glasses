# Team work split

The implementation owner integrates and tests the product. Other members can work in parallel without writing to the main branch.

1. Technical research: verify the exact board revision, camera and microphone support, power needs, official pin map, and compile instructions. Supply links and evidence.
2. Exhibition visuals: poster, system architecture diagram, flowchart, privacy diagram, and slides. Label planned vs implemented features accurately.
3. Test and QA: maintain the test matrix, record exact results, measure latency, and run repeated demo rehearsals.
4. Budget and presentation: itemized budget, demo script, short project report, viva questions and answers.
5. Integration owner: laptop app, model setup, firmware integration, security, release freeze, and final demo.

Use screenshots or links in shared team documents. Do not share private Wi-Fi passwords, dashboard PINs, device tokens, or personal data.
